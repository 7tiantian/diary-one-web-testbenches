# 02 · 事实接地（AI01）测试台

## 测什么
S04/结果中的**具体断言**是否都能追到证据帧；是否出现无依据的身份/亲属/「第一次」等编纂。

## 为何商用必测（PRD）
- **AI01 事实优先**：不猜亲属、情绪、因果、纪念意义
- 算法运行成功 ≠ 内容可信；商用 iOS 展示前必须过真实性门槛
- handoff：事实带 `evidence_frame_ids` / representative_frame

## 输入
- X02 / BFF job 的 preview JSON（可粘贴或上传）
- 本台提供 `sample_preview.json` 练习打分流程
- **人工**对照缩略图/原文勾选「有证据 / 无证据」

## 怎么测
1. 导入真实跑出来的 preview JSON
2. 系统列出 chapters/ahas/observations 中的陈述
3. 评审员逐条点「有证据」或「编纂/无证据」
4. 看量化通过率

## 输出
- 陈述列表 + 人工标签
- 接地率、编纂条数、自动可追溯帧覆盖率

## 量化指标
| 指标 | 计算 | 通过线（建议内测） |
|------|------|-------------------|
| 自动帧引用覆盖率 | 带 evidence_frame_ids 的事实 / 全部事实 | ≥ 95% |
| 人工接地通过率 | 标「有证据」/ 已评条数 | ≥ 90% |
| 严重编纂数 | 亲属/第一次/庆祝成功等无据 | = 0 |

## 启动
```bash
cd 02_grounded_facts_ai01
python -m http.server 5172
```
