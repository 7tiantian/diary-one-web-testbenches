# 04 · Aha / 小记忆独立性测试台

## 测什么
Aha（用户侧小记忆）数量、中文字数、是否与 Chapter 高潮重复、是否独立可回看。

## 为何商用必测
- **DIA03**：小记忆轻量、不可点详情、不显示类型名
- **AI02**：不与 Chapter 同一高光重复
- handoff：0–3 个；中文目标 20 字、硬上限 24；不得强行填充

## 量化指标
| 指标 | 通过线 |
|------|--------|
| Aha 数量 | 0–3 |
| 超过 24 可见字符条数 | = 0（不发布） |
| 人工「独立故事」率 | ≥ 85% |
| 人工「与 Chapter 重复高潮」 | = 0 |

cd 04_aha_independence
