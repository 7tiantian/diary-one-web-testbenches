# 05 · 媒体精选与 Hero（S10 / AI02）测试台

## 测什么
每个可见 Chapter 的精选媒体数量（3–5）、是否有 Hero、人工对封面/重复/低质的判定。

## 为何商用必测
- **AI02**：Hero 来自本记忆精选；选图不能反向造事
- handoff：Chapter 3–5 件；不得因过度去重删掉合格 Chapter
- iOS 详情页默认 poster、点击才播——封面错了体感直接坏

## 量化指标
| 指标 | 通过线 |
|------|--------|
| 每章 media 数 ∈ [3,5] 的章占比 | ≥ 90%（可见章） |
| 缺 Hero 章数 | = 0 |
| 人工「封面正确」率 | ≥ 85% |
| 人工「低质被选」章数 | = 0（阻断建议） |

cd 05_media_selection
