# 03 · Chapter 结构与边界（AI02 / DIA02）测试台

## 测什么
一天结果里 Chapter **数量是否在编辑目标内**、是否可展示、人工对「该拆/该合/无关混入」的判定。

## 为何商用必测
- **AI02**：Chapter=相对一致经历，不是地点文件夹；数量目标不能迫使生成
- **DIA02**：允许少生成、允许没有；3–4 是目标不是硬填满
- handoff：常规 3–4，丰富日可 5；不得机械配额

## 输入
- preview JSON（真实 X02/BFF 结果）
- 评审员对每个 Chapter 的边界判决

## 量化指标
| 指标 | 通过线 |
|------|--------|
| 可见 Chapter 数 ∈ [0,5] | 必须 |
| 目标带 [3,4] 命中或诚实更少 | 记录占比；丰富日允许 5 |
| 人工「边界正确」率 | ≥ 80%（已评章） |
| 「无关素材混入」章数 | = 0（阻断级） |
