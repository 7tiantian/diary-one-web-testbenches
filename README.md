每个台目录下：

```powershell

# 浏览器打开 README / 页面提示的本机端口
```

## 注意

- 不要把真实用户素材提交到未授权外网。
- 不要把 API Key、Token、`.env` 提交进 Git（已在 `.gitignore` 排除）。
- `09` 为团队个人 Key 联调例外；正式产品密钥只在自有后端。
