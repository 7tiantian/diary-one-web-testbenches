# T01 · 主动选入

## 测什么
只处理本次系统选择器明确返回的照片和视频。取消、未选的不进账本、不读取、不上传；来源固定为相册测试。

## PRD

## 输入 / 操作

## 通过条件
- 未选素材不进账本
- 取消选择不读取不上传
- 来源标记为 PHOTO_LIBRARY_TEST
